# Rift Armory

Fabric mod for Minecraft 1.21.11.

## Weapons
- Rift Mace - explosion at the aim point
- Dragon Mace / Dragon Spear - dash with stability cost
- Lightning Mace - chain lightning (3 targets), self-strike in rain
- Ghost Mace - invisibility phase
- Ghost Spear - hits through walls
- Rift Spear - long-range explosion
- Annihilation Stick - massive explosion with broadcast

## Items
Rods, hearts and the Rift Chest (random loot on use).

Build: GitHub Actions -> Artifacts -> riftarmory.jar
